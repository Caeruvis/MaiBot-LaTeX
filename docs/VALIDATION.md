## 限制与待现场验收

1. **真实平台投递** ：QQ/NapCat/SnowLuma 的图片限制、混排显示、最终消息 ID、超时后是否已部分送达尚未核验。自动路径不补发或回退源码。
2. **运行时联调** ：本次执行的是实际 SDK 和宿主函数体的隔离测试，没有启动完整 IPC 进程组。实际安装后需要检查两个钩子的注册、能力授权和浏览器配置。
3. **识别边界** ：常规程序代码和无法判定的无标记数学文本保留；卡片、文件和合并转发内部不解析。无法保证识别所有没有边界标记的 LaTeX。
4. **流式范围** ：完整回复输入已覆盖分隔符跨聚合片段；没有宣称接入逐 token 对外发送接口。
5. **严格保护可用性** ：补丁要求保护插件在线，插件关闭会停止所有经该发送服务的出站消息；适配器绕过发送服务直发需要另外接入。
6. **版本兼容** ：兼容声明限定 1.3.19 / 2.21.0。宿主升级、未知文本改写插件和其他操作系统尚未验收。

这些限制与已通过测试分开记录，不作为已完成的线上验证。
