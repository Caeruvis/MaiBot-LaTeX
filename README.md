## MaiBot LaTeX 公式渲染插件

作者：**Caeruvis** 。版本：**0.1.1** 。语言：中文。目标：**MaiBot 1.3.19 / maibot-plugin-sdk 2.21.0** 。安装前须在 `_manifest.json` 中填写作者主页和仓库地址。

**自动回复会保留说明文字，把已识别公式替换为图片；渲染失败使用“（公式暂时无法显示）”，不会回退发送公式源码。** 用户可直接发送 `/latex`、`/tex` 或 `/公式`，命令后的全部内容作为数学代码渲染。该命令不需要管理员权限、唤醒词、模型决策或自动渲染开关。

**本版本必须配套安装随包宿主补丁。** 目标宿主的前置回复钩子失败后可能继续发送原文。补丁增加回执检查，确保保护失败时停止发送。保护插件失联、停用或缺少回执时，补丁会停止经过发送服务的出站消息，包括普通文字；停用插件前应先撤销补丁。详细证据见 [接口核实](docs/INTERFACES.md)，实际测试见 [验证记录](docs/VALIDATION.md)。

## 使用

直接发送以下任一命令即可，无需给裸公式再添加美元符号：

```text
/latex \frac{a+b}{c}
/tex \int_0^1 x^2\,\mathrm{d}x
/公式 \begin{pmatrix}1&2\\3&4\end{pmatrix}
```

支持命令后的换行，也接受用 `$$...$$`、`\[...\]`、`\(...\)`、`$...$` 包住的单个公式，以及完整 `latex` / `tex` 围栏代码块。空命令返回用法。命令匹配后中止普通聊天处理，避免再由模型重复回答。

自动模式示例：模型回复 `质能关系为 $E=mc^2$。`，平台收到按“质能关系为 ”、公式图片、“。”排列的图文消息。插件使用原发送流程保留会话与引用关系，每条回复为一条有序消息序列，平台的具体显示布局由适配器决定。

“随时可直接调用”的运行前提是机器人在线、插件和命令启用、消息已经进入宿主命令链且平台允许发送。插件无法绕过宿主的全局禁用、平台封禁或断网。把 `plugin.auto_render` 设为 `false` 后，自动回复中的公式变为提示，手动命令仍能渲染。

## 安装

1. **停止机器人** ，确认宿主源码为核实过的 1.3.19，SDK 为 2.21.0。先备份宿主的 `src/maisaka/builtin_tool/reply.py` 和 `src/services/send_service.py`。补丁的原文件 SHA-256 位于 `docs/host-source-hashes.json`。
2. 解压包，将整个 `caeruvis_latex` 文件夹放进机器人实例的 `plugins` 目录。保留 `vendor`、`latex_engine` 和 `_manifest.json`。**应用补丁前**，在 `_manifest.json` 的 `author.url` 和 `urls.repository` 填写对应的 HTTP(S) 地址，确认插件能通过宿主校验。在 **Host 源码根目录** 执行下列补丁检查和应用命令，其中路径替换为实际解压位置。

```sh
patch --dry-run -p1 -i /绝对路径/caeruvis_latex/docs/host-1.3.19-fail-closed.patch
patch -p1 -i /绝对路径/caeruvis_latex/docs/host-1.3.19-fail-closed.patch
```

3. 若检查提示不匹配，应先核对源码；本包只验证了记录哈希对应的版本。补丁修改两个现有宿主文件并新增 `src/services/latex_guard.py`。若宿主已应用过包含链接例外的旧补丁，请用同一版本的原始文件恢复 `src/plugin_runtime/runner/manifest_validator.py`。
4. 确保宿主具备 **Playwright 和 Chromium/Chrome** ，启用宿主配置 `[plugin_runtime.render]` 的 `enabled = true`。宿主可使用已有浏览器；macOS 示例：

```toml
[plugin_runtime.render]
enabled = true
executable_path = "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
```

5. 插件本身只使用 SDK 和 Python 标准库；KaTeX 及字体已包含。启动后 Runner 自动生成 `config.toml`，也可从 `config.example.toml` 复制后调整。Python 要求 **3.11+** ，本次实测 **3.14.6 / macOS arm64** 。
6. 启动后检查插件及两个钩子已加载，再在测试会话中发送 `/latex \frac{1}{2}`，然后验证一条含说明文字和多个公式的自动回复。真实平台验收尚未在本次工作中执行。

回滚时先停止机器人，再在 Host 根目录用 `patch -R -p1 -i /绝对路径/caeruvis_latex/docs/host-1.3.19-fail-closed.patch` 撤销补丁，最后移除插件目录。升级 Host 后需要重新核对接口并重新生成补丁。

## 支持范围

| 内容 | 自动识别 | 处理规则 |
|---|---|---|
| `$...$`、`$$...$$` | 支持 | 转义美元不作分隔符，支持多行 |
| `\(...\)`、`\[...\]` | 支持 | 单/双反斜杠按真实转义关系判断 |
| `latex` / `tex` 围栏 | 支持 | 只支持数学表达式和 KaTeX 数学环境 |
| 分数、上下标、根式、积分、矩阵、aligned | 支持 | 已生成实际 PNG 并检查显示 |
| `$5，预算 $10` 等常见金额 | 保留文字 | 使用金额边界规则，混合歧义文本建议明确使用 `\(...\)` |
| 普通代码块、行内代码 | 保留文字 | 作为程序代码处理，其中美元符号不自动解释为数学 |
| 未闭合公式 | 保守隐藏 | 保留开头说明，隐藏从开符号至消息末尾的内容 |
| 无标记的 `\frac` 等命令或 `\未知命令{...}` | 保守隐藏 | 无可靠结束边界时隐藏该位置后的尾部，手动命令可渲染裸公式 |
| 无标记 `x+y=1`、无法确定的裸文本 | 保留文字 | 不能无歧义区分自然文本、代码和所有 LaTeX |
| 完整 TeX 文档、宏包、TikZ、外部图片/链接指令 | 不支持 | 明确失败，禁止显示 KaTeX 的红色源码回退 |

**公式识别承诺有明确边界** ：常规代码中的原文字面量和无法识别的无标记文本不属于自动公式识别范围。想稳定得到图片，应让模型使用规定分隔符；自动处理无需模型调用工具。

本实现接收**完整回复** ，在文本清洗和拆分前处理。核实的目标链路没有把增量片段直接交给本插件发送；测试包含聚合后分隔符跨片段的输入，不宣称支持对外逐 token 流式发送。跨独立平台消息的半个公式无法可靠恢复。

## 配置与运行行为

- 默认字号 **28** CSS 像素、图片倍率 **2** 、四边留白 **16** 像素；颜色和尺寸可配置。超过最大宽高时整条公式显示失败提示，不截断、不缩小到不可辨认，也不改公式含义。
- 单公式默认最多 **6000** 字符，每条消息最多 **12** 个公式；全文超过 **32000** 字符时整条替换为安全提示。渲染默认并发 **2** ，排队和执行合计超时 **8 秒** 。
- 图片缓存仅在内存中，键包含公式、显示模式、全部渲染设置和后端版本；默认 **128** 条、**900 秒**，另有总字节限制与周期清理。公式标记绑定会话，**180 秒** 过期，最多 **512** 条；失效标记只显示提示。
- 自动转换只改写待发消息，不在钩子中再次发送。手动命令按会话串行、不同会话独立，相同入站消息 ID 在 **180 秒** 内不重复发送。不同原始消息使用相同公式仍正常发送，图片缓存不充当消息去重。
- 普通附件、@ 和引用段保持原样；当前自动解析范围是发送序列中的文本段。合并转发内部、卡片、文件内容及其他插件私有载荷不作递归解析，见接口文档中的边界。
- 图片发送明确失败时，手动命令仅尝试发送简短提示；自动回复沿用 Host 的失败回执，不重发整条图文。平台可能已部分接受消息，无法同时承诺“必达”和“绝不重复”；这一状态需要真实适配器验收。

## 常见问题

- **全部回复停止** ：先检查插件是否加载及保护回执是否存在。严格补丁要求插件参与发送；插件停用时必须恢复插件或撤销补丁。
- **公式都变成提示** ：检查宿主渲染开关、浏览器和 Playwright、输入语法、尺寸与超时。测试工具 `tools/render_smoke.py` 可在本地验证浏览器，平台错误提示不会包含源码、堆栈或内部路径。
- **加载提示链接为空** ：在 `_manifest.json` 填写 `author.url` 和 `urls.repository` 后重新加载插件。
- **智能分段或语音插件** ：本机智能分段插件用原文哈希查缓存，本插件替换公式后该缓存不会命中，含公式回复保持完整。其他插件在保护回执之后再次改正文会被严格补丁拒绝；语音/卡片转换链路需独立联调。

## 文件与复现

入口是 `plugin.py`；`latex_engine` 包含解析、渲染、保护回执和配置；`docs` 包含接口证据、验证结果和宿主补丁；`tests` 包含故障与协议测试；`vendor` 包含离线 KaTeX。

在已安装 SDK 2.21.0、pytest 的开发环境中执行：

```sh
MAIBOT_SOURCE=/绝对路径/MaiBot-1.3.19 python -m pytest -q
python tools/render_smoke.py /绝对路径/MaiBot-1.3.19 --browser /绝对路径/chrome
python tools/package.py
```

第二条还需要 Playwright 和 Pillow，用于真实渲染与检查图片；插件运行依赖中没有这两个额外开发依赖。执行结果分别记录在验证文档和实际渲染 JSON 中。
